# kintone メンテナンス管理プラグイン

kintone アプリにメンテナンス画面（アクセスブロック）を表示し、特定ユーザー以外を一時的に制限するためのプラグインです。

## 🌟 主な機能

- **2つの動作モード**:
  - **対象アプリモード**: メンテナンス期間中にアクセスをブロックし、専用の画面を表示します。
  - **管理アプリモード**: メンテナンス情報の登録・対象アプリの選択・日時指定を行う管理用 UI を提供します。
- **3種類のデザインテーマ**:
  - Clean White, Dark Cyber, Gradient の 3 種類をランダムまたは固定で表示可能です。
- **柔軟なバイパス制御**:
  - メンテナンス中であっても、管理アプリで指定した「ユーザー」「組織」「グループ」に所属するユーザーは通常通り操作可能です。
- **デバイス標準の時計 UI**:
  - スマートフォン（iOS/Android）や PC の標準時計を呼び出して直感的に時間を指定できます。分は自動的に 00 分に丸められます。

## 🛠️ セットアップ方法

### 1. メンテナンス管理アプリの作成
以下のフィールドを持つアプリを 1 つ作成してください。

| フィールド名 | フィールドコード | 型 | 備考 |
| :--- | :--- | :--- | :--- |
| ステータス | `Is_Active` | ドロップダウン | 有効 / 無効 |
| 開始日時 | `Start_Datetime` | 日時 | |
| 終了日時 | `End_Datetime` | 日時 | |
| メッセージ | `Message` | 文字列(複数行) | ブロック画面に表示されます |
| 対象アプリIDs | `Target_App_IDs` | 文字列(1行) | プラグインが自動保存します |
| 組織選択 | `Bypass_Orgs` | 組織選択 | バイパス（許可）対象 |
| グループ選択 | `Bypass_Groups` | グループ選択 | バイパス（許可）対象 |
| ユーザー選択 | `Bypass_Users` | ユーザー選択 | バイパス（許可）対象 |

また、管理アプリ側で「時計UI」と「アプリ選択UI」を表示するための**スペースフィールド**を 2 つ配置してください。
- 要素ID: `time_picker_space`
- 要素ID: `app_select_space` (または任意のID)

### 2. プラグインのインストール
1. `plugin.zip` を kintone システム管理に読み込ませます。
2. **管理アプリ**にプラグインを追加し、設定画面で「管理アプリモード」を選択し、スペースIDと保存フィールドを指定します。
3. **メンテナンス対象アプリ**にプラグインを追加し、設定画面で「対象アプリモード」を選択し、管理アプリのアプリIDを指定します。

## 📦 パッケージング

プラグインを修正して `plugin.zip` を再生成する場合は、以下のコマンドを実行してください。

```bash
npx @kintone/plugin-packer --ppk <秘密鍵ファイル>.ppk .
```
